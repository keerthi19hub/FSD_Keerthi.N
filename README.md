## 1. Laboratory Overview

The **Full-Stack Development (FSD)** laboratory documents progressive web development coursework at **Alliance University**. It tracks the progression from core semantic HTML markup to modern responsive CSS layouts and interactive client-side JavaScript.

---

## 2. Topic Taxonomy & Exercise Catalog

### 🎨 UI & Layout Design
- `Alliance_Login_Form.html` & `Facebook_Login_Form.html` & `Instagram_Login_Page.html`: Authentication UI clones with CSS styling and input grouping.
- `Netflix.html`: Streaming platform hero landing page layout.
- `navbar.html`: Responsive navigation header with flexbox styling.
- `RWD.html`: Responsive Web Design with CSS media queries.
- `tables using js.html`: Dynamic HTML table rendering.

### ⚡ JavaScript DOM Manipulation & Event Handling
- `DOM in js.html`: Document Object Model traversal and dynamic node modification.
- `Event handlers in js.html`: Click, mouseover, and keyboard event listener implementations.
- `Digital Clock using js.html`: Real-time clock using `setInterval` and `Date` objects.
- `calcii_marriage_js.html` & `calculator_page.html`: Arithmetic evaluation engines with input button matrices.

### 🧩 Core JavaScript Programming
- `Basics and variables in js.html`: Variable scoping (`let`, `const`, `var`).
- `arrays & objects in js.html` & `Fruits(array)_company(obj) in js.html`: Object literals, array iteration, and transformations.
- `Functions.html`: Function declarations, expressions, and arrow functions.
- `loops in js.html` & `Switch statements in js.html` & `conditions in js.html`: Control structures and conditional branching.
